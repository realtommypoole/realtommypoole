## 🧪 Featured Work

### [RAG Optimization](https://github.com/realtommypoole/LLMRAGOptimize)

An applied AI project exploring how fine-tuning and evaluation can improve retrieval-augmented generation (RAG).

- Focus: improving the quality of retrieval-augmented question answering.
- Approach: exploring fine-tuning and evaluating its effect on system performance.
- Key question: what actually improves an AI system—and how do we know?

### [SLAM-Lite – Drone Visual Mapping & Trajectory Estimation](https://github.com/wushuchris/aai-521-group-7)

A collaborative visual odometry project using the GrapeSLAM UAV dataset to estimate drone trajectories in vineyard environments.

- Pipeline: ORB feature detection and matching, RANSAC-based pose estimation, and trajectory smoothing.
- Evaluation: positional error, RMSE, and drift against GPS ground truth, with attention to lighting, motion blur, and flight conditions.
- Results: reported trajectory RMSE of 0.445 m after GPS-based scaling and Procrustes alignment, compared with 8.885 m before alignment.

### [VoiceSync AI – Emotion Detection ML System](https://github.com/payalpt/aai-540-group-7)

A collaborative speech emotion detection system built on AWS SageMaker, spanning data infrastructure, model deployment, and monitoring.

- Pipeline: Amazon S3, Athena, SageMaker Feature Store, CloudWatch monitoring, and CI/CD with an accuracy gate.
- Results: XGBoost achieved a macro F1 score of 0.64; the real-time endpoint had reported latency under 20 ms.
- My contributions: data collection, data infrastructure, Athena setup, and monitoring dashboards.

### [Healthcare Billing Prediction – Machine Learning Project](https://github.com/nabecan/Final-Project-AAI-510-Team-2.ipynb)

A collaborative AAI 510 project comparing regression models to predict hospital billing amounts from synthetic healthcare data.

- Workflow: exploratory data analysis, preprocessing, and regression model comparison.
- Architecture: proposed cloud-based batch inference design for generating predictions.
- Findings: Linear Regression performed best among the models evaluated, though weak feature correlations limited predictive insights.


## 🧭 How I approach problems

Define the problem → establish a baseline → evaluate alternatives → document trade-offs and limitations.

I’m interested in the space between “the demo works” and “this is worth deploying.”

That means asking:
- What are we trying to accomplish?
- Have we identified the problem?
- How are we measuring success?
- What are the cost, risk, and operational trade-offs?
- What evidence would change our decision?
